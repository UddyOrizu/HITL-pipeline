# Sending work for review

Use **Send for review** to send a document or some text to a reviewer. You'll find the decision and the review record afterwards under [Sent by me](sent-by-me.md).

**Who can use this:** Submitters.

**Where to find it:** Left menu, **Send work** section, **Send for review**. There is also a **Send for review** button at the top of [Sent by me](sent-by-me.md).

## How to send a file

1. Select **Send for review** in the left menu.
2. Under **Workflow**, choose the workflow the work should go through. Each one shows its stages in brackets, in order.
3. If you like, type a name in **Title (optional)**. It makes the work easier to find later.
4. Under **Content**, keep **Upload a file** selected.
5. Select **Choose a file** and pick the file. You can send .docx, .pptx, .ppt, .pdf or .txt files. The file's name and size then show; select it again to change it.
6. Set **Risk tier**, **Written by** and, if it applies, **AI model (optional)**. See the table below.
7. If you have source material, add it under **Reference documents (optional)**. You can pick several files at once.
8. Select **Submit for review**.

You are taken to [Sent by me](sent-by-me.md) with the message "Submitted. It's been routed to a reviewer." Your new item is opened in the list.

## How to send pasted text

1. Follow steps 1 to 3 above.
2. Under **Content**, select **Paste text**.
3. Paste or type the content into the box.
4. Carry on from step 6 above.

## How to send a revised version

When a reviewer has asked for changes to, or rejected, something you sent, you can send a new version that is linked to the original.

1. Go to [Sent by me](sent-by-me.md) and select **Revise and submit again** on the item.
2. **Send for review** opens with a notice starting **Revision of …**. The workflow and title are filled in from the original.
3. Add the revised file or text and complete the rest of the form as usual.
4. Select **Submit for review**.

The new item is recorded as a revised version of your earlier one. If you opened the form this way by mistake, select **Not a revision? Submit as new**; this clears the link, the title and the workflow.

## What the fields mean

| Field | What to enter |
|---|---|
| **Workflow** | The review route for this work. Your organisation sets up the workflows; the first one in the list is chosen if you don't pick. |
| **Title (optional)** | A short name, for example "Client letter – Hartley". If you leave it blank, the item is listed by a short reference code. |
| **Content** | **Upload a file** or **Paste text**. You must give one or the other. |
| **Risk tier** | **Low**, **Medium** or **High**. It starts on **Medium**. Ask your administrator if you are unsure which to use. |
| **Written by** | **AI**, **A person** or **Both**. It starts on **AI**. |
| **AI model (optional)** | The name of the AI tool that wrote it, if you know it. The box is switched off when **Written by** is **A person**. |
| **Reference documents (optional)** | Source material the reviewer can check claims against, such as a client file. The reviewer can read these but is not approving them. Same file types as above. |

## Common questions

**The Submit for review button is greyed out.**
You need a workflow and some content: either a chosen file or some pasted text.

**"No workflows accept web submissions yet. Ask an admin to set one up."**
No workflow has been opened up for sending work from this page. An oversight lead sets these up under [Review workflows](settings-review-workflows.md).

**"The original workflow is no longer available, so choose another."**
You are sending a revision, but the workflow the original used has been removed or closed. Pick a different one under **Workflow**.

**An error appears after I select Submit for review.**
The message says what went wrong. Your form stays filled in, so correct the problem and select **Submit for review** again.

**Can I change or take back something after sending it?**
You can't edit it, but while it is still being reviewed you can withdraw it. See [Sent by me](sent-by-me.md).
